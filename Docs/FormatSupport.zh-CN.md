# 格式支持

[English](FormatSupport.md)

## 描述文件支持矩阵

| 能力 | 状态 | 说明 |
| --- | --- | --- |
| 文本描述 | 支持 | 覆盖带引号的值、任意字段顺序、BOM 和多页文件。 |
| XML 描述 | 支持 | 包括紧凑的单行 XML 和可选 XML 声明。 |
| 二进制描述 v3 | 支持 | 块 1–5、有符号度量、Unicode ID，以及未知块警告。 |
| 二进制描述 v1/v2 | 拒绝 | 导入器报告不受支持的版本。 |
| 多页 | 支持 | 页面 ID 映射到声明的文件和纹理。 |
| Unicode 标量 ID | 支持 | 增补平面码点按一个字形解码。 |
| 字偶距（kerning） | 支持 | 在字间距（tracking）之前应用。 |
| Packed 通道 | 支持 | 页面通过通道提取材质渲染，详见下文。 |

## 导入校验

- 描述文件的行高和图集尺寸必须为正。
- 声明的页面数量必须与解析后的页面记录一致。
- 页面 ID 必须非负，但不必连续；页面资源上限约束页面记录数量，不约束 ID 的数值。
- 每个字形必须引用已知页面，且位于声明的图集范围内。
- 每个页面文件必须位于描述文件目录之下。绝对路径和 `..` 不得越出该目录。
- 导入的源纹理尺寸必须匹配 `scaleW` 和 `scaleH`。
- 重复字形和 kerning 记录采用最后一个值，并产生警告。
- 包含 `DOCTYPE` 声明的 XML 描述在 XML 解析之前被拒绝。

## 解析器资源上限

导入器在读取描述数据之前和过程中应用 `FBMFontParserLimits`。C++ 调用者可以向 `Parse`、`ParseText`、`ParseXml` 或 `ParseBinary` 显式传入上限对象；单参数重载和编辑器导入器采用以下默认值：

| 资源 | 默认上限 |
| --- | ---: |
| 描述文件字节数 | 64 MiB |
| 解码后的描述字符数 | 64 Mi 字符 |
| 文本行数 | 2,250,000 |
| 单个文本行的字符数 | 65,536 |
| XML 元素数 | 1,200,000 |
| XML 属性数 | 5,000,000 |
| 图集页面记录数 | 256 |
| 字形记录数 | 1,112,064（Unicode 标量值数量） |
| Kerning 记录数 | 1,000,000 |
| 页面文件名字符数 | 1,024 |
| 单页图集的宽或高 | 16,384 像素 |
| 单页图集像素数 | 67,108,864 |
| 所有声明页面的总像素数 | 268,435,456 |

XML 元素和属性上限由轻量扫描检查，发生在 Unreal 构建 XML DOM 之前。即使重复记录之后会合并成一条映射，仍按原始记录数量应用上限。解析诊断最多保留 256 条；最后一条报告后续诊断被抑制。仅含警告的输入仍保留警告级别，但如果任意被抑制诊断是错误，该条会提升为错误。这些限制约束解析工作量和声明的纹理规模；引用图片的实际格式解码仍由 Unreal 纹理解码器负责。

## 图片格式

页面解码交由 Unreal 的 `UTextureFactory` 处理。PNG 有自动化导入测试覆盖。特定 Unreal 安装支持的其他格式可能可用，但不在当前兼容性声明中。

## Packed-channel 渲染

`common.packed=1` 时，字形使用插件 `M_BMFontPacked` UI 材质的动态实例渲染，不直接绘制原始纹理。渲染资源按页面 ID 和字形的 `char.chnl` 掩码缓存，因此共享图集矩形但位于不同通道的字形仍相互独立。材质结合 `char.chnl` 与 `alphaChnl`、`redChnl`、`greenChnl`、`blueChnl` 恢复覆盖率：

- `char.chnl` 使用 BMFont 位掩码：蓝 `1`、绿 `2`、红 `4`、alpha `8`，全部通道为 `15`。
- 掩码内标记为 **Glyph** 或 **Glyph + Outline** 的通道提供采样覆盖率。
- 选中通道标记为 **One** 时，覆盖率恒为 1，即实心字形矩形。
- 通道元数据缺失或相互矛盾时，渲染器仍遵循字形通道掩码。如果描述文件既没有可用字形掩码，也没有可用元数据，则回退到 alpha。

Outline 通道不单独合成；packed 图集的描边外观合并在提供字形覆盖率的通道中。资产可以通过 **Packed Render Material** 属性覆盖材质，但必须保持 `FontAtlas`、`ChannelWeights` 和 `ChannelBias` 参数约定。

Packed 页面纹理导入时禁用 sRGB，因为通道表示覆盖率，不是显示颜色。重导入保留已有纹理设置，因此最初从非 packed 描述导入的纹理会继续启用 sRGB 并产生警告；这种情况下需要手动禁用 sRGB。

## 文本行为

- 支持显式 CR、LF 和 CRLF 换行。
- 制表符按四个空格字形的步进前进，不计入缺字数量。
- 自动换行使用 Unreal 的断行迭代器。`AllowPerCharacterWrapping` 提供与 Unreal 文本控件相同的长词逐字符回退行为。
- 缺少的源字符优先使用 `FallbackCodepoint` 对应字形；该字形也不存在时，按半个行高前进，并增加缺字计数。
- `info.spacing` 作为图集生成器元数据保留。它描述生成位图图集时采用的间距；运行时使用各字形的 `xadvance` 和 `common.lineHeight`，不会再次叠加。
- 布局和渲染从左到右，不提供 OpenType shaping、连字、组合附加符定位或双向重排。

用于阿拉伯文、印度文字或其他依赖塑形的文字系统时，BMFont 图集应显式包含并寻址最终呈现字形；即使如此，自动完成符合语言规则的塑形仍不在本插件当前范围内。
